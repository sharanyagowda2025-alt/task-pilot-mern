# 🚀 TaskPilot

**TaskPilot** is a full-stack task management and productivity web application built with the **MERN stack** (MongoDB, Express.js, React, and Node.js). It helps users organize, prioritize, and track daily tasks through a clean, responsive dashboard.

## ✨ Features
- **User Authentication:** Secure registration and login powered by JSON Web Tokens (JWT) and password hashing.
- **Full CRUD Task Management:** Create, view, update, and delete tasks seamlessly.
- **Task Organization:** Categorize tasks by status (Pending, In Progress, Completed), priority levels, and due dates.
- **Search & Filter:** Quickly locate specific tasks using real-time search and status/priority filters.
- **Responsive Dashboard:** Clean UI designed for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** React, CSS3 / Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (with Mongoose ODM)
- **Authentication:** JWT (JSON Web Tokens) & bcrypt
